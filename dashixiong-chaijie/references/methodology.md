# 方法论标尺① — 创新点套路 + Gap 识别

> 本文档是「拆解」时给论文定性用的**标尺**。拆维②创新点套路、维⑦Gap 时，逐条对照本文档，把论文往这些「抽屉」里归。

---

## 一、五大创新套路（给「造创新」的手法定性）

拆一篇论文的创新点，先回答：**作者是用哪种套路把创新点造出来的？**

### 套路①：应用创新 —「知识搬运工」 ★★

**核心逻辑**：把已有方法搬到新问题，或把新方法用到老问题。
- 新问题 + 老方法（把成熟方法用到新出现的对象上）
- 老问题 + 新方法（把别领域新方法用到本领域老问题上）

**论文里的识别信号**：
- 方法本身很成熟、很常见（常见实验、经典模型、通用算法）
- 但研究对象/场景是新的，或近年才火起来
- Introduction 里常出现「X 方法已被广泛用于 A、B、C 领域，但尚未用于 D」

**经典案例**：机器学习 + 任何传统工科；深度学习 + 医学影像。

**可复制性判断**：
- 若该方法在目标领域已有 1-2 篇 → 你还有窗口（越早越优）
- 若已有很多人做过 → 是跟风不是创新
- 难度最小，适合新手，三四区常见。

### 套路②：修改创新 —「画蛇添足 / 大材小用」 ★★★

**核心逻辑**：对现有理论/方法增删变量。
- **画蛇添足式**：`F(x,y,z) → F(x,y,z,u)`，在经典模型上**加一个变量**反映更特定的问题
- **大材小用式**：`F(x,y,z) → F(x)`，把复杂理论**简化**用于简单场景

**论文里的识别信号**：
- 模型/公式里有个「新增项」「修正系数」「影响因子」
- 结论里强调「在考虑 X 因素后，模型精度显著提升」
- 或反过来「将原本复杂的三维方法简化为工程实用的解析/一维公式」

**经典案例**：传统强度准则里加「温度影响因子」；完整有限元模型简化为工程解析解。

**可复制性判断**：
- 新增变量必须**有明确物理意义 + 真实应用场景**（不是随便加）
- 简化后精度仍需满足工程要求
- 难度适中，最容易出成果。

### 套路③：融合创新 —「学术裁缝的缝合怪」 ★★★

**核心逻辑**：多个已有方法拼合——第一部分用 A 理论，第二部分用 B 理论，第三部分用 C 理论，综合达到更优效果或新功能。

**论文里的识别信号**：
- 方法部分有「结合 / 耦合 / 集成 / 联合（combined/coupled/hybrid/integrated）」
- 研究对象是多过程、多尺度、多物理场的复杂问题
- 关键创新点常落在「接口设计」（两个方法怎么衔接、数据怎么传递）

**可复制性判断**：
- 必须证明「1+1>2」（融合后确实比单一方法好）
- 接口设计是核心难点也是创新点
- 需要较宽的文献视野。

### 套路④：比较创新 —「测评师」 ★★★★

**核心逻辑**：系统比较测试多种已有方法，找出最适用者，或做改进/融合。

**论文里的识别信号**：
- 论文主体是「我们比较了 A、B、C、D 四种方法在同一问题下的表现」
- 结论常是「方法 X 在条件 Y 下最优，建议…」
- 题目常含「comparative study / evaluation / assessment / review of methods」

**可复制性判断**：
- 必须公平（相同数据、相同条件）、指标全面（精度+效率+鲁棒性）
- 最好给出「什么情况用什么方法」的应用建议
- 工作量大但成果扎实。

### 套路⑤：理论/方法创新 —「大佬操作」 ★★★★★

**核心逻辑**：提出全新理论框架或评价方法，从无到有。

**论文里的识别信号**：
- 新概念、新理论框架、新本构、新范式
- 题目含「a new theory / framework / paradigm / first」

**可复制性判断**：**不建议新手直接照抄**。拆到这种论文，重点是学习它的「论证严密性」和「问题定义高度」，而非复制手法。

## 二、加/减/改/换（拆「具体动了哪个变量」）

定性到五大套路后，再细拆：**作者具体对已有研究做了什么改动？** 这是最落地的「套路指纹」。

| 手法 | 含义 | 论文里的表现 |
|------|------|-------------|
| **加** | 增加参考论文没考虑的变量/因素/工况 | 「首次考虑了温度/耦合/多场/高周循环的影响」|
| **减** | 简化复杂环节提高可行性 | 「将三维模型简化为工程实用的一维公式」|
| **改** | 替换材料/工况/应用场景（每次只改 1-2 个关键变量）| 「把方法从 A 材料换成 B 材料」|
| **换** | 换一种方法研究同一个问题 | 「别人用实验，我用数值；别人用 FEM，我用 DEM」|

> 铁律：**每次只动 1-2 个关键变量**。全换变量 = 颠覆性创新，三四区没人干这个。

## 三、五大 Research Gap 类型（识别「作者自曝的缝」）

拆维⑦时，把作者在 Introduction / Discussion 里承认的局限，归到以下五类。**每条 Gap 都对应一个「你能切入的缝」。**

| # | Gap 类型 | 定义 | 论文里的识别信号 |
|---|---------|------|----------------|
| ① | **缺乏研究型** | 某问题没人做过 | "there is a lack of research on..." / "no established method exists" |
| ② | **局限性型** | 现有研究有明显局限，没考虑更复杂因素 | "However, this method assumes..." / "limited to..." / "further work is needed to consider..." |
| ③ | **宽泛不适用型** | 现有研究太宽泛，对具体场景不适用 | 通用方法在特殊场景误差大 / 规范推荐做法不适用特殊情况 |
| ④ | **低效型** | 方法效率/精度有短板 | "computationally expensive" / "the error is still significant" / 参数太多 / 对初值敏感 |
| ⑤ | **理想化型** | 假设过于理想，简化过多 | "assuming that..."（强假设）/ 各向同性、稳态、线性 / Discussion 提「实际工程更复杂」|

**拆解动作**：找出作者在 Discussion 里「认怂」的句子（limitations / future work / beyond the scope），逐条归类，每条写一句「→ 由此可切入：XXX」。

## 四、创新等级矩阵（标含金量）

| 创新等级 | 组合方式 | 目标期刊层次 |
|---------|---------|-------------|
| 最高 | 新问题 + 新方法 | Top 期刊、领域顶刊 |
| 较高 | 老问题 + 新方法 | Top 期刊、主流一区 |
| 中等 | 新问题 + 老方法 | 主流期刊（一区/二区）|
| 较低 | 老问题 + 老方法 | 一般期刊或难发表（增量改进，慎选）|

**「新」的界定**：新问题 = 近 3-5 年出现的现象/工况/需求；新方法 = 近 3-5 年在其他领域兴起、尚未在本领域广泛用；老问题/老方法 = 已存在 10 年以上、有大量积累。

> 拆解时：给这篇论文标一个「创新等级」，你就知道它的含金量来自哪、你自己照做能对标到几区。

## 五、创新点「显式表达」手法（拆「怎么写出来」）

造出创新点还不够，得会**写出来让审稿人看见**。拆维②时，检查作者有没有在这些位置反复提名创新点：

| 位置 | 作用 | 信号词 |
|------|------|--------|
| Title | 首次曝光 | novel / new / enhanced / mechanism / first |
| Abstract 第 2-4 句 | 直接点出 | "Here we present/propose/demonstrate..." |
| Introduction 末段 | 详细阐述贡献 | "The key innovation of this work is..." / "Unlike previous approaches..." / "To the best of our knowledge, this is the first study to..." |
| Conclusion 第 1 段 | 再次强调 | "This paper presented a novel..." |

**拆解动作**：检查这四个位置是否都提名了同一创新点（用了不同粒度但一致的核心表述）。这是判断作者「会不会包装」的关键，也是你以后写自己论文要照抄的手法。
