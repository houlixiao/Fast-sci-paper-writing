# 套路卡片 Schema + 套路库索引格式

> 本文档定义「沉淀」的两种产物：①每篇拆解报告的目录；②套路卡的标准格式 + 跨篇索引。核心目标是：**拆 N 篇后，能按套路类型反查、跨论文复用。**

---

## 一、套路卡标准字段

每张卡固定 frontmatter + 四个字段。**格式统一才能跨篇累积、可检索。**

```markdown
<!-- 卡片类型：innovation | method | sentence | structure | figure | gap -->
### [套路名]

- **类型**：innovation（创新套路）/ method（方法套路）/ sentence（句式）/ structure（结构）/ figure（图表）/ gap（可切入的缝）
- **来源**：[论文简称]，见 `[论文简称]_拆解.md`
- **用法**：这篇论文怎么用的（1-3 句，落到可操作层面）
- **可复制性**：能迁移到什么场景 / 什么条件下别用
- **关键词**：tag1, tag2, tag3
```

> 规则：一张卡只记**一个**可复用套路。一篇论文拆出多张卡。卡片追求「一句话能抄走」，拒绝泛泛的「本文系统研究了 X」。

## 二、各类型卡片模板 + 示例

### 创新套路卡（type: innovation）
```markdown
### 修改创新·画蛇添足——在经典强度准则里加温度因子
- **类型**：innovation
- **来源**：xxx_paper，见 xxx_paper_拆解.md
- **用法**：在已有 Mohr-Coulomb 准则基础上加一个温度衰减系数 η(T)，把常参数改成随温度变化，验证高温工况下预测精度提升。
- **可复制性**：任何「已有模型 + 一个被忽略的影响因素」都能照抄；前提是新因子有物理意义、有可标定数据。
- **关键词**：修改创新, 增变量, 强度准则, 温度
```

### 方法套路卡（type: method）
```markdown
### 数值方法链——「1 组实验标定 + 1 组数值 + 对比验证」
- **类型**：method
- **来源**：xxx_paper，见 xxx_paper_拆解.md
- **用法**：用三轴试验标定本构参数 → 建有限元模型 → 用同一试验结果验证模型 → 跑参数化工况 → 从数据提炼机理。
- **可复制性**：三四区最稳的链，无需新设备，工作量约 3-6 个月；难点在参数标定要讲清楚、验证要有对照。
- **关键词**：方法链, 数值模拟, 参数标定, 模型验证
```

### 句式卡（type: sentence）
```markdown
### 机制归因句式——「Two factors contribute: First… Second…」
- **类型**：sentence
- **来源**：xxx_paper，见 xxx_paper_拆解.md
- **用法**：描述现象后接 "This can be attributed to two factors. First, [机理1]. Second, [机理2]." 把现象上升为机制。
- **可复制性**：Results 每个发现都能套，直接解决「只会描述不会解释」的痛点。
- **关键词**：五步法, 机制解释, 归因
```

### 结构卡（type: structure）
```markdown
### Intro 四段式——把「现有研究不足」单独成段
- **类型**：structure
- **来源**：xxx_paper，见 xxx_paper_拆解.md
- **用法**：第1段背景 → 第2段综述 → 第3段专写「现有不足」（First/Second/Third 逐条列，各带不利影响）→ 第4段本研究。
- **可复制性**：四段式比三段式更稳，第3段专列不足能让创新点「师出有名」，推荐写 SCI 时直接用。
- **关键词**：Intro, 四段式, 研究不足
```

### 图表卡（type: figure）
```markdown
### 创新点对比示意图——左「现有问题」右「本方案」
- **类型**：figure
- **来源**：xxx_paper，见 xxx_paper_拆解.md
- **用法**：一张概念图，左框画现有方法的局限，右框画本方法的优势，中间箭头标核心创新，让审稿人 10 秒看懂贡献。
- **可复制性**：任何论文都能加这张图，放在 Intro 末尾或 Methods 开头；作图成本低、性价比极高。
- **关键词**：示意图, 创新点, 对比图
```

### Gap 卡（type: gap）
```markdown
### Gap·理想化——「假设各向同性，实际各向异性」
- **类型**：gap
- **来源**：xxx_paper，见 xxx_paper_拆解.md
- **用法**：作者在 Discussion 承认模型假设土体各向同性；由此可切入——放宽该假设，引入各向异性本构。
- **可复制性**：直接对接下一篇选题；凡 Discussion 有「assume/limitation」处都是入口。
- **关键词**：Gap, 理想化, 放宽假设, 切入点
```

## 三、拆解报告目录结构

每篇一份 `[论文简称]_拆解.docx`（Word），放在当前工作目录（格式规范见 SKILL.md §5.2）。内容结构：

```markdown
# [论文标题] 拆解报告

> 一句话创新点：XXX（Step 0 锚点）

## 0. 论文元信息
- 类型 / 期刊 / 年份 / 作者 / DOI
- 创新等级（新问题×新方法 / 老问题×新方法 / …）

## 1. 结构拆解（Section → 段落）
## 2. 创新点套路 ★
## 3. 研究方法套路 ★
## 4. 论证/写作套路（句式骨架 + 填空模板）
## 5. 图表套路
## 6. 引用架构
## 7. 可切入的缝(Gap)
## 8. [多篇时] 交叉综合
## 附：本篇套路卡（已追加进 _套路库索引.md）
```

## 四、套路库索引格式（跨篇沉淀）

固定文件名 `_套路库索引.md`，放当前工作目录。**按套路类型组织（不是按论文）**，方便写 SCI 时「按套路反查」。

```markdown
# 论文拆解·套路库索引

> 拆解记录：N 篇。按套路类型反查：写 SCI 时，先想「我想用哪种套路」，再翻对应案例看别人怎么落地。

## 一、创新点套路库
### 修改创新
- [套路名](来源论文_拆解.md) —— 一句话用法
- ...
### 应用创新
- ...

## 二、方法套路库
- [套路名](来源论文_拆解.md) —— 一句话方法链
- ...

## 三、句式库
- [套路名](来源论文_拆解.md) —— 一句话句式骨架
- ...

## 四、结构库
- ...

## 五、图表库
- ...

## 六、Gap 库（可切入的缝）
### 理想化型
- [Gap描述](来源论文_拆解.md) —— 由此可切入：XXX
### 局限性型 / 缺乏研究型 / 宽泛不适用型 / 低效型
- ...
```

## 五、沉淀规则

1. **每拆必沉淀**：拆完一篇，把维①②③④⑤⑦的可复用套路按 §二 的卡格式抽卡，追加到 `_套路库索引.md` 对应分类下。
2. **去重合并**：若新卡与已有卡套路相同（如同一套路不同案例），在已有条目下**追加一条「新案例」**，不新建重复条目——这样同一套路下能积累多个案例，反查时信息更全。
3. **卡片锚定**：每张卡必须用 `来源` 字段指向对应的 `[论文简称]_拆解.md`，方便回看原文。
4. **索引更新**：拆完更新索引顶部的「拆解记录：N 篇」计数。
5. **命名**：论文简称建议用「第一作者+年份+主题词」或「标题前 3 个实词」，保证不重名、可读。
