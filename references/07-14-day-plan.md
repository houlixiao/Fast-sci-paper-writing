# 07 | 14 天完成 SCI 初稿：派生执行安排

> **出处说明**：《2周干完SCI写作教程与模版》实际包含六个章节的写作套路，并未给出逐日的十四天工作表。以下为本 Skill 基于六部分原则额外设计的**条件性工作计划**，不是原文逐日安排。

## 启动前提

这一时间表针对**主要实验或模拟已完成、关键图表和基础文献可用**时的初稿生产；不包含凭空完成尚未进行的实验、数值验证、伦理审批或漫长审稿。必要数据不足时应先改为“补数据/补验证计划”。

| 天数 | 核心任务 | 当天可交付成果 |
| --- | --- | --- |
| D1 | 归档研究问题、创新点、目标期刊与材料 | 研究目标卡片、文件清单、期刊要求 |
| D2 | 整理验证/实验/模拟数据与参数来源 | 数据—结果—图表映射、证据缺口表 |
| D3 | 确认正文图表及其逻辑顺序 | 图表目录、每图一个主要论点 |
| D4 | Methods I：模型/材料、控制方程、几何和边界 | 方法初稿前半 |
| D5 | Methods II：工况、参数来源、标定、验证设计 | 方法初稿后半、参数表 |
| D6 | Results I：验证与关键基准对照 | 验证结果段、关键误差说明 |
| D7 | Results II：机制过程与代表性变量 | 结果正文与图表引用 |
| D8 | Discussion：物理解释、文献对照、限制 | 讨论段落及未解问题 |
| D9 | Conclusions：3–5 项证据支持的成果 | 简洁结论稿 |
| D10 | Introduction I：背景与问题综述 | 引言的背景和现状 |
| D11 | Introduction II：缺口、研究目标、创新点 | 引言完成稿 |
| D12 | Abstract、Title、Keywords | 摘要及候选标题 |
| D13 | 内部一致性核查与语言润色 | 全文审校清单、修订版 |
| D14 | 对照期刊要求、图表编号、参考文献交叉核查 | 可供导师/合作者审阅的初稿 |

## 每日运行方式

读取当日任务和已有材料 → 识别是否已有足够证据 → 生成指定章节草稿/审查记录 → 更新完成进度。没有图表或关键验证时不得为了赶天数“填空式制造结果”。用户已有章节可以跳过，并重新安排剩余天数。

完成度建议用：`已完成 / 需补证据 / 等待确认 / 不适用`，并列出对应文件路径；不要将“文字已写完”误判为“方法已验证”。
