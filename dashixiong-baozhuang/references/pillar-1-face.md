# Pillar 1: 面子工程操作手册

## 一、排版规范检查

### 1.1 标题层级检查
- 确保论文使用三级标题体系（H1 → H2 → H3），不跳级
- 一级标题通常为粗体14pt居中，二级为粗体13pt左对齐，三级为粗斜体12pt左对齐
- 检查是否有孤立的标题（标题后没有正文内容）
- 标题命名应简洁、信息量大，不用问句做标题

### 1.2 正文排版
- 正文字体：Times New Roman 12pt（或目标期刊指定字体），双倍行距
- 段落首行缩进：0.5英寸（或目标期刊规范）
- 页边距：上下2.54cm，左右3.17cm（或目标期刊规范）
- 页眉页脚：通常包含页码、短标题（running head）
- 避免出现大段空白区域

### 1.3 参考文献格式
- 严格遵循目标期刊的引用格式（APA/Vancouver/Harvard/ACS/自定义）
- 检查文中引用和参考文献列表的一一对应
- 参考文献编号连续，无跳号
- DOI/URL 完整且可访问

### 1.4 公式与符号
- 所有数学符号使用斜体（变量）或正体（常量、单位）
- 公式编号连续
- 首次出现的符号必须定义

## 二、图片优化

### 2.1 现有图片检查
- 分辨率 ≥ 300 DPI（打印标准）
- 配色统一，同一类数据使用一致的色系
- 图例、坐标轴标签字体足够大（≥ 8pt），清晰可读
- 图表标题格式统一（Figure X. 描述）

### 2.2 建议新增的图

#### 核心创新点示意图
- **位置**：Introduction 末尾或 Methods 开头
- **内容**：用可视化方式展示本研究的核心创新逻辑
- **类型**：概念图、原理图、对比图
- **要求**：让审稿人一眼看懂你论文的核心贡献是什么

#### 论文逻辑框架图
- **位置**：Methods 开头
- **内容**：展示研究的整体技术路线 / 工作流程
- **类型**：流程图（问题 → 方法 → 验证 → 结论）
- **要求**：让审稿人快速理解论文结构

### 2.3 图表配色建议
- 使用色盲友好的配色（避免红绿单独对比）
- 推荐配色方案：
  - 主色：深蓝 #1f77b4
  - 辅色：橙 #ff7f0e、绿 #2ca02c、红 #d62728
  - 背景：白色或无背景
- 同一篇论文中同类图表使用统一配色

## 三、语言润色

### 3.1 高优先级润色区域
按影响力排序：Abstract > Introduction > Conclusion > Discussion > Results > Methods

### 3.2 润色清单（常见问题）

**语法层面**：
- 主谓一致（第三人称单数 -s）
- 时态一致（Methods/Results 用过去时，Discussion/Conclusion 中一般事实用现在时）
- 冠词（a/an/the 的使用）
- 介词搭配（depend on, related to, compared with...）
- 单复数（data 是复数，phenomenon → phenomena）

**表达层面**：
- 消除口语化表达（a lot of → many/considerable; big → large/significant; get → obtain）
- 缩短冗长句式（It is worth noting that → Notably, ...）
- 避免重复用词（同一个词在相邻句子中出现 >2 次需要替换）
- 统一术语（全文中同一概念使用相同术语）

**逻辑层面**：
- 确保每个段落的主题句明确
- 段落之间有逻辑过渡词
- 因果关系的表达准确（due to, because of, owing to, attributed to 的正确使用）

### 3.3 润色策略
- 保持学术语气——客观、准确、克制
- 不要过度复杂化句子——清晰优先于华丽
- 改动最小化原则——能改一个词解决的问题不改整句
- 保留作者的个人风格和术语习惯
- 如果某段存在无法在不虚构内容的前提下修复的结构性问题，**标记出来而不是强行修改**
