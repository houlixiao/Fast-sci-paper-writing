# 通用SCI期刊模板（默认）

## 页面设置
- 纸张：A4 (210 × 297 mm)
- 页边距：上下 2.54 cm (1 inch)，左右 3.17 cm (1.25 inch)
- 分栏：单栏（双栏仅限部分期刊，默认使用单栏）

## 字体
- 正文字体：Times New Roman, 12pt
- 一级标题字体：Times New Roman, 14pt, Bold, 居中
- 二级标题字体：Times New Roman, 13pt, Bold, 左对齐
- 三级标题字体：Times New Roman, 12pt, Bold Italic, 左对齐
- 图表标题字体：Times New Roman, 10pt
- 页眉/页脚字体：Times New Roman, 10pt

## 段落
- 正文行距：双倍行距（Double-spaced）
- 段落首行缩进：0.5 inch (1.27 cm)
- 段前/段后间距：0pt（双倍行距期刊通常不在段间额外加空白）
- 参考文献行距：单倍行距，条目之间加空行

## 标题层级
- 一级标题 (H1): 14pt, Bold, 居中, 编号为 1., 2., 3. ...
- 二级标题 (H2): 13pt, Bold, 左对齐, 编号为 1.1, 1.2, 2.1 ...
- 三级标题 (H3): 12pt, Bold Italic, 左对齐, 编号为 1.1.1, 1.1.2 ...

## 图表
- 图表嵌入正文中，尽量靠近首次引用的位置
- 表格标题在表格上方，图片标题在图片下方
- 编号格式：Figure 1., Figure 2. ... / Table 1., Table 2. ...
- 图片分辨率：≥ 300 DPI

## 参考文献
- 默认格式：编号引用 [1], [2], [1-3]（Vancouver 风格变体）
- 参考文献列表按出现顺序编号
- 如有 DOI，建议包含

## 其他
- 页脚包含页码（居中）
- 首页可包含通讯作者信息
- 缩写首次出现时给出全称
- 摘要字数：通常 150-250 词

## 适用场景
当你无法确定目标期刊格式要求时，使用此通用模板。它满足大多数 SCI 期刊的基础排版要求。如果投稿被格式问题打回，再根据具体期刊的 Author Guidelines 微调。
