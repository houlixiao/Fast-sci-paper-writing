# IEEE 系列期刊模板

## 适用期刊
- 所有 IEEE 旗下期刊和会议（Engineering, Computer Science, Electrical Engineering 等）
- 包括：IEEE Transactions on XXX, IEEE Access, IEEE Sensors Journal 等

## 页面设置
- 纸张：US Letter (216 × 279 mm)
- 页边距：上下 1.78 cm，左右 1.78 cm
- 分栏：**双栏**（IEEE 的标志性特征）

## 字体
- 正文：Times New Roman, 10pt（双栏排版下字号较小）
- 标题：Times New Roman, 24pt, 居中
- 一级标题：Times New Roman, 10pt, Bold, 小型大写字母
- 二级标题：Times New Roman, 10pt, Italic
- 图表标题：Times New Roman, 8pt

## 段落
- 正文：单倍行距
- 段首缩进：0.25 inch
- 双栏之间的间距：0.25 inch

## 结构要求
IEEE 论文结构：
1. Introduction
2. [Related Work / Background]
3. [Proposed Method / System Model]
4. [Experimental Setup / Simulation Settings]
5. [Results and Discussion]
6. Conclusion

## 摘要
- 150-250 词
- 单段
- 包含关键词（Index Terms）

## 参考文献
- 编号引用：[1], [2], [1]-[3]
- IEEE 引用格式（方括号内编号）
- 作者首字母 + 姓氏格式
- 期刊名缩写

## 图表
- 嵌入双栏内（单栏宽）或跨双栏（整页宽）
- 图表标题在下方（Figure X.）
- 表格标题在上方（TABLE X.）
- 矢量图优先（PDF/EPS），位图 ≥ 300 DPI

## IEEE 特有要求
- 论文标题下作者行包含 IEEE 会员级别标注
- 页脚包含版权声明行
- 不包含作者照片和简介（部分 Transactions 除外）
- Mathematics 部分推荐使用 IEEE Math Typesetting Guide

## 投稿注意
- IEEE 对格式要求非常严格，格式问题可能直接退稿
- 使用 IEEE 官方模板（LaTeX 或 Word）
- 页数限制因期刊而异（通常 8-14 页双栏）
- 附信（Cover Letter）推荐撰写
