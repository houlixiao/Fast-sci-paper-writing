# Pillar 2: 创新点包装 + 学术故事模板

## 一、创新点提取

### 1.1 创新点类型识别

在审稿人看来，最有价值的创新点有两类：

**类型A：物理机制类创新**
- 特点：在问题现象背后解释内在物理机制
- 天然优势：具有研究深度——揭示了前人没有发现的机制
- 识别信号：mechanism, underlying, fundamental, physical insight, driving force, root cause

**类型B：实际应用类创新**
- 特点：对实际生产生活有指导意义
- 天然优势：具有研究实际意义
- 识别信号：evaluation method, prediction model, empirical formula, design guideline, practical application

### 1.2 创新点提取方法
1. 从 Abstract 中找"我们做了什么不一样的事"
2. 从 Introduction 末尾找"本文的贡献/创新"
3. 从 Conclusion 中找"本文的核心发现/贡献"
4. 如果以上三个地方都没有明确的创新表述 → 从 Methods 中分析研究方法的新颖之处

### 1.3 创新点数量
**一篇二区论文，1个核心创新点就够了。** 不要贪大求全。如果论文有多个创新点，选择最突出的那个重点包装，其他简略带过。

## 二、标题重写

### 2.1 标题模板

**模板1（方法创新类）**：
```
A novel [XX model/technique/method/approach] to [evaluate/predict/capture/characterize] 
the [responses/behavior/properties/performance] of [X] under [Y condition]
```

**模板2（机制揭示类）**：
```
[XX mechanisms] of [研究对象] under [试验条件] using [研究方法]: 
[A key insight or finding]
```

**模板3（简短有力类）**：
```
[Key finding]: [concise description of the main contribution]
```
例：`Enhanced thermal stability of perovskite solar cells via interfacial engineering`

### 2.2 标题检查清单
- [ ] 包含核心创新关键词（novel, new, enhanced, improved, etc.）
- [ ] 不超过25个词
- [ ] 没有冗余词（"Study on...", "Research on...", "Investigation of..." 等低信息量开头）
- [ ] 核心创新点能被审稿人一眼看到

## 三、学术故事构建

### 3.1 四段式 Introduction 结构

这是最经典高效的 Introduction 结构：

```
段落1: 研究背景（大背景 → 具体问题）
  └─ 为什么要研究这个问题？有什么工程/科学意义？

段落2: 现有研究进展（文献综述）
  └─ 前人做了哪些工作？取得了什么进展？

段落3: 现有研究不足 ⬅ 新增重点！
  └─ 但现有研究还存在什么问题？有什么不足？
     - 方法A的局限性...
     - 研究B没有考虑...
     - 领域C缺乏对...的研究
     - 这些不足导致了什么不利影响？

段落4: 本研究
  └─ 本文提出了什么方法/做了什么工作来解决上述问题？
     - 与现有工作相比有什么优势？
     - 预期取得什么成果？
```

### 3.2 "现有研究不足"段落模板

```
However, existing studies have several limitations. First, [具体不足1], 
which leads to [不利影响1]. Second, [具体不足2], making it difficult to 
[不利影响2]. Third, limited attention has been paid to [被忽视的问题], 
despite its importance in [重要性]. 

These gaps motivate the need for [本研究的方向].
```

**关键原则**：
- 不足必须是具体的、可验证的（不是空洞的"研究不够"）
- 不足要和你的创新点形成呼应（你的创新正好解决这些不足）
- 不要恶意贬低他人工作（专业、客观的语气）

### 3.3 创新点显式表达

在以下关键位置**反复提名**创新点（至少各提1次）：
1. **Title** — 首次曝光
2. **Abstract 第2-3句** — 直接点出
3. **Introduction 第4段** — 详细阐述
4. **Conclusion 第1段** — 再次强调

使用"信号词"引导审稿人注意：
- `Here we present/propose/demonstrate...`
- `The key innovation of this work is...`
- `Unlike previous approaches, our method...`
- `This work addresses the long-standing challenge of...`
- `To the best of our knowledge, this is the first study to...`

### 3.4 讲故事（吹牛）的技巧

**不要说**："We improved the accuracy by 5%."
**要说**："The proposed method achieves a 5% accuracy improvement over state-of-the-art approaches, enabling more reliable prediction of [重要应用场景], where existing methods fail due to [根因]."

**公式**：
```
[你做了什么] + [相比现有水平好在哪里] + [这个改进有什么用] + [为什么之前做不到]
```

**另一个角度——不只讲"做了什么"，还要讲"为什么重要"**：
- 不好："We developed a new composite material."
- 好："We developed a lightweight composite that maintains structural integrity at 1200°C — a temperature regime where conventional lightweight materials catastrophically fail — opening new possibilities for [应用场景]."

## 四、创新点示意图

### 4.1 图的类型
**推荐：对比型示意图**（最直观）
- 左边：现有方法的问题/局限
- 右边：本研究的解决方案/优势
- 中间：箭头或桥梁，标注核心创新

### 4.2 图的内容要素
- 简洁的图形元素（框、箭头、图标）
- 关键文字标注（不超过30个词）
- 配色与论文整体统一
- 让审稿人**10秒内**看懂创新点

### 4.3 图注模板
```
Figure X. Schematic illustration of the core innovation. (a) Conventional approaches 
suffer from [limitation]. (b) The proposed method overcomes this by [key innovation], 
enabling [key advantage].
```
