# 输出规范

## 输出文件 1: 包装版 .docx

### 文档结构
```
[封面/标题页 - 可选]
包装说明页（改动摘要）
正文：
  Title
  Abstract
  Keywords
  1. Introduction
  2. Related Work / Literature Review
  3. Methods / Experiments
  4. Results
  5. Discussion
  6. Conclusion
  References
  [Appendix - 如有]
```

### 排版规范（默认通用模板）
| 元素 | 规格 |
|------|------|
| 页面 | A4 (210×297mm) |
| 页边距 | 上下 2.54cm，左右 3.17cm |
| 正文字体 | Times New Roman, 12pt |
| 正文行距 | 双倍行距 |
| 一级标题 | Times New Roman, 14pt, Bold, 居中 |
| 二级标题 | Times New Roman, 13pt, Bold, 左对齐 |
| 三级标题 | Times New Roman, 12pt, Bold Italic, 左对齐 |
| 图表标题 | Times New Roman, 10pt |
| 参考文献 | 按目标期刊规范 |

如果用户指定了目标期刊/出版社，加载对应的 `references/journal-formats/` 模板替代以上默认值。

### 图表嵌入
- 新增示意图嵌入在正文合适位置（创新示意图在 Introduction 末尾，逻辑框架图在 Methods 开头或 Results 开头）
- 图片格式：PNG，分辨率 ≥ 300 DPI
- 图片下方带编号和标题

### 包装说明页
在文档开头（标题页之后、正文之前）插入一页"包装说明"（中文撰写，专业术语可保留英文），包含：
- 包装日期
- 三大支柱改动概要（每个支柱 2-3 句话，中文描述）
- 重要提示：哪些改动需作者确认（中文）
- "本包装由 AI 辅助完成，不涉及数据修改。投稿前请全面审阅。"

### 改动高亮标注
包装版文档中所有相较于原文档的改进之处（新增段落、重写段落、大幅修改段落）均使用**黄色高亮（yellow highlight）**标注，方便作者快速定位和审阅改动。原文中保留不变的段落不加高亮。诊断报告中详细列出所有改动，与高亮一一对应。

## 输出文件 2: 诊断报告 .docx

用 docx-js 生成 Word 格式诊断报告，内容参照 `assets/diagnostic-report-template.md`。

### 排版规格
- 与包装版使用相同排版规范（A4、Times New Roman 12pt、双倍行距）
- 中文撰写
- 表格使用 docx-js Table 组件

### 报告内容（中文）

1. **论文信息**：文件名、论文类型、目标层次
2. **总体评估表**：三大维度的原状态 vs 包装后评分
3. **面子工程改动详情**：语言润色数量、排版调整建议、新增图表说明
4. **创新点包装详情**：核心创新点提取、新标题建议、叙事逻辑改造说明
5. **工作量包装详情**：数据分析深化、方法细节补充、文献审查结果、验证建议
6. **投稿前待办清单**：作者需逐条确认的事项

评分标准（1-5星）：
- ⭐ — 4区水刊水平
- ⭐⭐ — 4区中等水平
- ⭐⭐⭐ — 3区水平
- ⭐⭐⭐⭐ — 2区水平
- ⭐⭐⭐⭐⭐ — 1区/顶刊水平

---

## 核心约束

1. **不改数据**：所有数值、表格、公式、统计结果保持原文不变
2. **不加实验**：不编造未做的实验或未收集的数据
3. **不虚构引用**：不添加不存在的参考文献
4. **不改变结论**：研究结论的实质内容不变，只优化表达方式
5. **透明可追溯**：诊断报告详细记录所有改动，方便作者逐条审核
